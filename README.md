# CUE SAMPLER

**Next-generation creative sampler and chop instrument for music producers.**

CUE SAMPLER is a proprietary audio plugin (VST3 / AU) featuring real-time stem separation, transient and bar-synced chopping, seamless DAW integration, and automated in-app updates.

---

## Downloads & Releases

Official installer packages are published directly on the **[Releases](https://github.com/cuevst-cmd/cuesampler/releases)** page:

- **macOS**: Download the latest signed and notarized `.pkg` installer (supports Apple Silicon and Intel).
- **Windows**: Download the latest signed `.exe` installer (64-bit VST3).

---

## Automatic Updates

CUE SAMPLER includes an integrated update checker that checks this repository for newly published builds. When an update is released, you will be notified directly inside the plugin editor with a one-click download link.

---

## System Requirements

- **macOS**: macOS 11.0 (Big Sur) or later. Apple Silicon (M1/M2/M3/M4) or Intel x86_64.
- **Windows**: Windows 10 (64-bit) or later.
- **Plugin Formats**: VST3, Audio Unit (AU v2).
- **DAW Compatibility**: Ableton Live, FL Studio, Logic Pro, Studio One, Reaper, Bitwig, Cubase, etc.
