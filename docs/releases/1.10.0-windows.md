# CUE SAMPLER 1.10.0 Windows build evidence

Prepared October 21, 2026, from `bd4544f` (`main`, matching `origin/main` after
fetch), plus the local Windows runtime and test fixes described below. The UI
displays **1.10**; the plugin and installer metadata use **1.10.0**.

Reused the x64 Release build directory `build-win-1.0.9` with MSVC 14.44.35207,
JUCE 8.0.12, ONNX Runtime DirectML 1.20.1, DirectML 1.15.2 and LAME 3.100.
Built the VST3, standalone application and offline validation targets. Automatic
plugin installation during building was disabled. The existing installer
workflow packages the VST3 only.

## Windows fixes

- Delay-import `mp3lame.dll` and preload it from the plugin's own directory,
  alongside the existing ONNX/DirectML handling. Before this fix, loading the
  VST3 from an unrelated directory with the default Windows DLL search path
  failed with Win32 error 126. Adding the plugin directory to PATH allowed that
  same binary to load. The corrected binary loads without a PATH change and
  returns a live VST3 factory.
- Stage the MP3 runtime beside the cache/state regression executables and require
  it in installer preflight.
- Add an absolute `CUE_USER_DATA_DIR` override and set it inside the state-test
  scratch directory. Tests isolate UI settings, update cache, legacy-file cleanup
  and retained drag exports as well as the existing stem cache. Normal application
  paths are unchanged when the override is unset.
- Make controller-installer tests check Windows readonly/readwrite semantics and
  skip symlink creation only when Windows reports missing symlink privilege.

## Validation

All seven selected CTest suites passed: `stem_cache`, `fl_link_protocol`,
`fl_link_controller`, `fl_link_installer`, `tempo_analysis`, `project_restore`
and `sample_import`. The full state/editor suite covers MIDI mapping, pads,
micro-chops, trimming, tails, MP3 exports, waveform controls and project recall.
The two state/import CTests took 39.25 seconds. The Python installer suite passed
eight tests and skipped its symlink case because this Windows account lacks that
privilege; the earlier POSIX-only assertions were corrected before the passing
run.

Real Beat This model checks passed for 1490, 1501 and 3000 frames, retaining exact
beat/downbeat lengths and finite probabilities across chunk boundaries.

The real HTDemucs integration passed separation, asynchronous cache/save/restore,
mute/remix and portable MP3-stem recall checks. Separation readiness took
15,335.1 ms; 724 editor callbacks had a maximum dispatch gap of 32.4558 ms.
The updated Windows editor's generated light-theme pad screenshot was visually
inspected. These checks do not establish compatibility with every GPU or DAW.

The VST3 and MP3 DLL are x64 PE binaries (machine `8664`). The VST3 metadata
reports 1.10.0. VST3 SHA-256:
`4a09d8fb0aab769f6d24a2211ab975136efd6d4aaaf29a85bb38887490561b6e`.

Build, test, model-check, plugin-load and packaging logs are in the gitignored
`build/windows-prep` directory. No DAW-hosted audio test has been run for this
candidate. FL typing-octave control is macOS-only; native laptop capture and the
recording Link remain excluded from the active plugin build.
