# CUE SAMPLER 1.10.1 Windows FL Studio fixes

Prepared October 21, 2026. The refreshed installer uses committed source
`ab6b0cd`, including the Windows fixes described in the 1.10.0 evidence and this
patch. The Release build was checked again before packaging and was up to date.

## Behavior

- Expose FL OCT controls on Windows and send paired Alt+numpad shortcuts to a
  usable FL window in the current process and GUI thread. Temporary keyboard
  modifier state is scoped to that thread and restored after dispatch. Requests
  reject held keys, text input, menus and modal/disabled windows.
- Keep FL's typing-keyboard MIDI path active while clicking CUE controls. The
  editor, waveform, non-text widgets and JUCE VST3 wrapper no longer take keyboard
  focus on normal clicks. Text fields still accept intentional text input.
- No MIDI-note transposition, chop remapping, global keyboard hooks or duplicate
  plugin-generated laptop MIDI were introduced.

## Validation and installed candidate

Rebuilt the x64 Release VST3 with MSVC using `build-win-1.0.9`. All three selected
CTest suites passed in 34.88 seconds: `host_keyboard_focus` (1.85 s),
`project_restore` (29.83 s) and `sample_import` (3.18 s).

The new focus test runs a harness copy named `FL64.exe` to exercise JUCE's real FL
host detection. It creates only an isolated hidden native host window and checks
passive editor/wrapper activation, waveform audition, control interaction,
exactly-once key-down/character/key-up forwarding, no duplicate local MIDI and
working trim text entry. No global keyboard input is used by that fixture.

The VST3 also passes the default-search-path load/factory check. The tested binary
and module metadata were installed with FL closed; previous installed files were
backed up in `build/windows-prep/installed-1.10.0-before-focus-fix`. The installed
binary reports 1.10.1 and matches the tested build by SHA-256:
`f8934582853d4bde01c08d631cdd04e5ff5be8b3c910104ebc0dea4ca9cff738`.

The plugin was reopened in FL Studio 2026 (26.1.6.5639, Windows x64), and OCT
controls were visible. Automated key taps did not give a reliable musical-note
observation. The user then tested physical laptop keys inside the plugin and OCT
changes and explicitly confirmed **both work**. Automated fixtures alone do not
establish behavior in every FL configuration, bridged process or other DAW.

Existing runtime/model files were retained for this verified local update. Build,
CTest, plugin-load, candidate-install and installed-hash logs are under the
gitignored `build/windows-prep` directory.
