# CUE SAMPLER 1.10.2 macOS release evidence

Prepared October 21, 2026, from `9abfe9a` plus the release changes committed with
tag `v1.10.2`. Version 1.10.1 was already present in the newer Windows source;
this release advances the shared project version to 1.10.2.

The Release build contains universal arm64/x86_64 AU and VST3 plugins, with a
macOS 11.0 deployment target. Automatic installation during building was disabled.
The installer includes ONNX Runtime 1.18.1, LAME 3.100, beat-analysis resources,
the compact HTDemucs graph, and the required notices and dependency source archives.
The compact model SHA-256 is
`c5ba957ab054c6f2940663dd0b1efc1cf1b63e2dee902b361cb982743185d7d5`.

## Release fixes

- Internal MP3 payloads now explicitly use JUCE's software decoder. On macOS,
  CoreAudio already removes encoder delay; applying the software decoder's
  1,105-sample trim again advanced restored audio and prevented short project
  fixtures from reopening. The existing software-decoder trim is retained,
  imported-file decoding is unchanged, and decoding remains in background jobs.
- The legal-resource helper respects configured FetchContent source-directory
  overrides when source paths are not provided explicitly. This checkout uses a
  shared LAME source tree outside the default `build/_deps` location.
- Installer packaging accepts `CUE_INSTALLER_TMPDIR` to place large staging files
  on an external drive explicitly instead of relying on macOS temporary-directory
  selection. The completed installer was packaged using this option.

## Validation

- All five selected C++ suites passed: `stem_cache`, `fl_link_protocol`,
  `project_restore`, `sample_import`, and `tempo_analysis`. The full editor/project
  suite passed in 15.69 seconds and sample-import checks in 1.05 seconds after the
  decoder fix. The earlier failing candidate was stopped before packaging.
- The unchanged stem-cache suite also passed unrestricted under both native
  arm64 and Rosetta x86_64, including the six alignment checks that exposed the bug.
- All 34 independent Python regressions passed: 16 controller, nine installer,
  and nine compact-model optimizer checks. Five focused legal-helper behavior
  checks passed, including configured paths with spaces and explicit overrides.
- Real compact-model separation passed cache, save/restore, mute/remix, and
  portable MP3-stem alignment checks. Readiness took 8,740.94 ms; 410 editor
  callbacks had a maximum dispatch gap of 24.4232 ms on this Mac.

Build and validation logs are retained under the gitignored `build` directory.
The installer is verified by extraction; these automated checks do not replace
manual DAW testing on each supported macOS and hardware combination.
